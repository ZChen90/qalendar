# Qalendar

A rolling 4-week global earnings calendar covering seven indices across five markets:
S&P 500, Nasdaq-100 (US) · Hang Seng Index (HK) · DAX 40 (DE) · FTSE 100 (UK) · CAC 40 (FR) · Nikkei 225 (JP).

- Pre-market / post-market sessions follow each company's home market.
- Known release times are converted to the viewer's local timezone automatically.
- Per-viewer watchlist, hidden companies and index filters (stored locally in the browser).
- Data is refreshed every trading-day morning by an automated pipeline.
